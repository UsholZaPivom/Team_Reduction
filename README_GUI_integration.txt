ИНТЕГРАЦИЯ GUI С ПРОЕКТОМ
=========================

Файлы:
- user_interface.py
- ui_backend_entry.py

Что умеет интерфейс:
1. выбрать папку проекта;
2. выбрать исходный Word-файл пользователя;
3. запустить анализ документа;
4. показать пользователю список новых сокращений для ручного выбора;
5. автоматически учесть сокращения, которые уже есть в документе;
6. выбрать режим вставки списка сокращений:
   - В конец документа
   - По маркеру
   - В существующий раздел сокращений
   - Отдельным файлом
7. выбрать, нужно ли дополнительно:
   - выполнить замену повторных объявлений;
   - сформировать отдельный файл со списком сокращений;
8. выбрать папку сохранения и имя итогового DOCX.

Как использовать:
1. Скопируйте оба файла в корень проекта, рядом с main.py.
2. Запустите:
   python user_interface.py
3. Укажите:
   - папку проекта;
   - входной DOCX;
   - папку сохранения;
   - имя итогового файла.
4. Нажмите:
   "Запустить анализ и загрузить варианты"
5. Отметьте нужные новые сокращения.
6. Запустите финальную обработку.

Что делает backend:
- analyze:
  запускает stage 3, который внутри использует stage 2;
- process:
  1. берёт existing_abbreviations.csv из stage 3;
  2. объединяет существующие сокращения и выбранные пользователем новые;
  3. при необходимости выполняет замену повторных объявлений;
  4. вставляет список сокращений в нужное место;
  5. сохраняет итоговый DOCX с именем пользователя.

Служебные результаты сохраняются в:
- result_ui_session/stage3
- result_ui_session/replacement_stage
- result_ui_session/generated
